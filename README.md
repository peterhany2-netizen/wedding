Peter & Mira Wedding Website — Netlify Ready

HOW TO PUBLISH:
1. Unzip this package.
2. Keep index.html and the assets folder together.
3. Go to https://app.netlify.com/drop
4. Drag the whole folder "peter_mira_wedding_netlify_ready" into the page.
   Do NOT upload only index.html.
5. Netlify will create a live website link.

IMPORTANT:
- index.html is now small.
- All photos and floral decorations are stored in the assets folder.
- Do not rename or move the assets folder unless index.html is updated too.
